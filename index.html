Map Rendering

        

          

            OpenFreeMap
            MIT
          

          
Vector tile hosting and the Bright map style. Free and open-source tile infrastructure built on top of OpenMapTiles and OpenStreetMap data.

        

        

          

            OpenMapTiles
            BSD + CC-BY
          

          
Vector tile schema used to encode OpenStreetMap data into the tiles served by OpenFreeMap. Developed by MapTiler and the OpenMapTiles community.

        

        

          

            CyclOSM
            BSD 3-clause
          

          
Cycle-oriented raster map style rendered from OpenStreetMap data. Tile server provided by OpenStreetMap France. Used under the OSM tile usage policy.

        

      


      

        
Mapping Libraries

        

          

            Leaflet 1.9.4
            BSD 2-clause
          

          
Interactive map library. Created by Volodymyr Agafonkin and maintained by the Leaflet community.

        

        

          

            MapLibre GL JS
            BSD 3-clause
          

          
WebGL-accelerated vector tile renderer. Open-source fork of Mapbox GL JS, maintained by the MapLibre community.

        

        

          

            MapLibre GL Leaflet
            ISC
          

          
Binding layer that integrates MapLibre GL JS as a Leaflet tile layer.

        

      


      

        
Routing & Geocoding

        

          

            BRouter
            MIT
          

          
Primary cycling routing engine. Calculates optimal bike routes using pre-processed OpenStreetMap data with configurable profiles. Uses the public brouter.de API.

        

        

          

            Valhalla (FOSSGIS)
            MIT
          

          
Fallback routing engine when BRouter is unavailable. Open-source routing engine hosted by FOSSGIS e.V. on openstreetmap.de, using OpenStreetMap data.

        

        

          

            Nominatim
            ODbL (data)
          

          
Address search and geocoding service powered by OpenStreetMap data. Hosted by the OpenStreetMap Foundation. Used in accordance with the Nominatim usage policy (max 1 req/s, triggered by user input only).

        

        

          

            Overpass API
            ODbL (data)
          

          
Read-only OpenStreetMap data API used to fetch cycling route overlays (ICN, NCN, RCN, LCN networks). Data is © OpenStreetMap contributors under ODbL.
